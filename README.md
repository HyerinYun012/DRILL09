# Drill #9: 소년 상하좌우 이동

pico2d로 캠퍼스 배경 위의 소년 캐릭터를 움직이고, 이동 상태와 마지막 좌우 방향에 맞는 애니메이션을 출력하는 과제입니다.

## 실행 환경

- Python 3
- pico2d
- 1280 × 1024 이상의 화면을 표시할 수 있는 환경

## 실행 방법

저장소 루트에서 다음 명령을 실행합니다.

```bash
python drill_9.py
```

`drill_9.py`, `TUK_GROUND.png`, `animation_sheet.png`는 같은 폴더에 있어야 합니다.

## 조작법

| 입력 | 동작 |
| --- | --- |
| `←` / `→` | 좌우 이동 및 바라보는 방향 변경 |
| `↑` / `↓` | 기존 좌우 방향을 유지하며 상하 이동 |
| 방향키 두 개 | 대각선 이동 |
| `ESC` | 프로그램 종료 |

창 닫기 버튼으로도 프로그램을 종료할 수 있습니다.

## 구현 기능

- 방향키를 누르는 동안 상하좌우로 연속 이동
- 수직·수평 키를 함께 누를 때 대각선 이동
- 서로 반대인 방향키 입력 상쇄
- 좌우 이동에 따른 방향 전환
- 수직 이동 및 정지 중 마지막 좌우 방향 유지
- 이동 중 8프레임 달리기 애니메이션
- 정지 중 8프레임 IDLE 애니메이션
- 캐릭터의 100 × 100 px 영역을 고려한 화면 경계 제한
- `ESC` 및 창 닫기 이벤트의 정상 종료 처리

## 실행 후 확인 항목

1. 캐릭터가 화면 중앙에서 오른쪽 IDLE 상태로 시작하는지 확인합니다.
2. 네 방향키를 각각 길게 눌러 연속 이동하는지 확인합니다.
3. 수직·수평 키를 함께 눌러 대각선 이동하는지 확인합니다.
4. 왼쪽으로 이동한 다음 상하로 이동해 왼쪽 방향이 유지되는지 확인합니다.
5. 방향키를 놓았을 때 마지막 방향의 IDLE 애니메이션으로 전환되는지 확인합니다.
6. 화면의 네 변과 모서리에서 캐릭터가 화면 밖으로 나가지 않는지 확인합니다.
7. `ESC`와 창 닫기 버튼으로 각각 정상 종료되는지 확인합니다.
